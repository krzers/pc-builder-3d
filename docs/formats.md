# Format ในการประกอบคอม และเว็บนี้ใช้ตัวไหนเช็ก

หลักของระบบ: ชิ้นส่วนสองชิ้นใส่ด้วยกันได้หรือไม่ ขึ้นกับ **format (มาตรฐาน)** ที่ทั้งคู่ใช้ ไม่ขึ้นกับยี่ห้อ เมนบอร์ด ATX ของยี่ห้อไหนก็ใส่เคสที่รองรับ ATX ได้ทุกยี่ห้อ ดังนั้นกฎเช็กทุกข้อควรเขียนเทียบ format หรือขนาด ไม่เขียนเทียบชื่อรุ่น

สถานะในตาราง: **เช็กแล้ว** = มีกฎใน `pairs()` · **ยังไม่เช็ก** = มีข้อมูลใน OpenDB แต่ยังไม่ได้เขียนกฎ · **ข้อมูลไม่พอ** = OpenDB ไม่มีหรือข้อมูลไม่ครบ

## 1. ขนาดเมนบอร์ด (motherboard form factor)

เป็น format ที่สำคัญที่สุด เพราะกำหนดตำแหน่งรูยึดและขนาดเคสขั้นต่ำ

| Format | ขนาด (มม.) | ช่องการ์ดสูงสุด | หมายเหตุ |
|---|---|---|---|
| Mini-ITX | 170 × 170 | 1 | เคสจิ๋ว มักมีช่องแรม 2 ช่อง |
| Micro-ATX | 244 × 244 | 4 | |
| ATX | 305 × 244 | 7 | ขนาดมาตรฐาน |
| E-ATX | 305 × สูงสุด 330 | 7 | ความกว้างไม่ตายตัว แต่ละรุ่นกว้างไม่เท่ากัน (ที่พบบ่อยราว 277) |
| Mini-DTX | 203 × 170 | 2 | พบน้อย |
| SSI-CEB / SSI-EEB | 305 × 267 / 305 × 330 | 7 | บอร์ดเวิร์กสเตชันและเซิร์ฟเวอร์ |
| XL-ATX, HPTX | ใหญ่กว่า ATX | 8+ | ไม่เป็นมาตรฐานกลาง พบน้อยมาก |

ตำแหน่งรูยึดของขนาดเล็กเป็นส่วนย่อยของขนาดใหญ่ เคสที่รองรับ ATX จึงมักใส่ Micro-ATX และ Mini-ITX ได้ด้วย แต่ระบบนี้ **ไม่เดาเอง** ใช้รายการ "ขนาดที่รองรับ" ที่ระบุไว้ของเคสแต่ละรุ่น

จำนวนใน OpenDB (เมนบอร์ด 3,701 รุ่น): ATX 1,688 · Micro-ATX 1,521 · Mini-ITX 301 · E-ATX 154 · ที่เหลือรวมกันไม่ถึง 40

| ความสัมพันธ์ | สถานะ |
|---|---|
| ขนาดเมนบอร์ด ↔ ขนาดที่เคสรองรับ | เช็กแล้ว |
| ความกว้างจริงของ E-ATX ↔ เคส | ข้อมูลไม่พอ (ไม่มีความกว้างรายรุ่น) |

## 2. ช่องเสียบซีพียู (socket)

| Format | ใช้กับ |
|---|---|
| AM4 | AMD Ryzen 1000–5000 |
| AM5 | AMD Ryzen 7000 ขึ้นไป |
| LGA1700 | Intel Core รุ่นที่ 12–14 |
| LGA1851 | Intel Core Ultra 200 |

| ความสัมพันธ์ | สถานะ |
|---|---|
| ซีพียู ↔ เมนบอร์ด (socket ต้องตรงกัน) | เช็กแล้ว |
| ชุดระบายความร้อน ↔ socket (ขายึด) | เช็กแล้ว |
| ซีพียู ↔ ชิปเซ็ตและเวอร์ชัน BIOS | ข้อมูลไม่พอ |

## 3. แรม

| Format | รายละเอียด |
|---|---|
| รุ่น | DDR4 กับ DDR5 ร่องคนละตำแหน่ง เสียบข้ามกันไม่ได้ |
| รูปทรง | DIMM (เดสก์ท็อป) กับ SO-DIMM (โน้ตบุ๊กและบอร์ดเล็กบางรุ่น) |

| ความสัมพันธ์ | สถานะ |
|---|---|
| รุ่นแรม ↔ เมนบอร์ด | เช็กแล้ว |
| จำนวนแถว ↔ จำนวนช่อง และความจุรวมสูงสุด | เช็กแล้ว |
| DIMM / SO-DIMM | ยังไม่เช็ก (ตอนนี้คัดมาเฉพาะ DIMM) |
| ความสูงแรม ↔ ฮีทซิงก์ | ข้อมูลไม่พอ (ไม่มีความสูงแรม) |

## 4. การ์ดจอ

| Format | รายละเอียด |
|---|---|
| ช่องเสียบ | PCIe x16 ใช้ร่วมกันได้ทุกเวอร์ชัน |
| ความหนา | นับเป็นช่อง ช่องละ 20.32 มม. (2, 2.5, 3, 4 ช่อง) |
| ความยาว | ไม่มีมาตรฐาน ต้องเทียบเป็นมิลลิเมตรกับเคส |
| หัวจ่ายไฟ | 6-pin (75 W) · 8-pin (150 W) · 12VHPWR / 12V-2x6 (สูงสุด 600 W) |

| ความสัมพันธ์ | สถานะ |
|---|---|
| ความยาว ↔ ความยาวสูงสุดที่เคสรับได้ | เช็กแล้ว |
| ความหนา ↔ จำนวนช่องการ์ดของเคส | เช็กแล้ว |
| หัวจ่ายไฟ ↔ สายของพาวเวอร์ซัพพลาย | ข้อมูลไม่พอ (ฝั่งการ์ดจอมีครบ แต่ฝั่ง PSU หลายรุ่นกรอกเป็น 0) |

## 5. พาวเวอร์ซัพพลาย

| Format | ขนาด กว้าง × สูง × ลึก (มม.) | ใช้กับ |
|---|---|---|
| ATX | 150 × 86 × 140 ขึ้นไป | เคสทั่วไป |
| SFX | 125 × 63.5 × 100 | เคสจิ๋ว |
| SFX-L | 125 × 63.5 × 130 | เคสจิ๋วที่มีที่พอ |
| TFX | 85 × 64 × 175 | เคสสลิม |
| Flex ATX | 81.5 × 40.5 × 150 | เคสเล็กมาก |

จำนวนใน OpenDB (3,308 รุ่น): ATX 3,089 · SFX 159 · TFX 26 · Flex ATX 13 · SFX-L 1

| ความสัมพันธ์ | สถานะ |
|---|---|
| format ของ PSU ↔ format ที่เคสรองรับ | เช็กแล้ว (เคสส่วนใหญ่ใน OpenDB ไม่ได้ระบุช่องนี้ จึงเช็กได้เฉพาะรุ่นที่ระบุ) |
| ความยาว PSU ↔ ความยาวสูงสุดของเคส | เช็กแล้ว |
| กำลังวัตต์ ↔ ไฟที่เครื่องใช้ | เช็กแล้ว (ค่าประมาณ) |

## 6. ที่เก็บข้อมูล

| Format | รายละเอียด |
|---|---|
| M.2 | กว้าง 22 มม. ยาว 30 / 42 / 60 / 80 / 110 มม. เรียก 2230, 2242, 2260, 2280, 22110 |
| 2.5 นิ้ว | SSD SATA และฮาร์ดดิสก์โน้ตบุ๊ก |
| 3.5 นิ้ว | ฮาร์ดดิสก์เดสก์ท็อป |
| การเชื่อมต่อ | NVMe (PCIe) หรือ SATA |

| ความสัมพันธ์ | สถานะ |
|---|---|
| SSD M.2 ↔ เมนบอร์ดมีช่อง M.2 | เช็กแล้ว |
| ความยาว M.2 ↔ ความยาวที่ช่องรองรับ | เช็กแล้ว (ใช้ความยาวที่ระบุของทุกช่องรวมกัน ช่องที่ระบุเป็นช่วง เช่น 2242-2260 นับทุกขนาดมาตรฐานในช่วงนั้น) |
| ไดรฟ์ 2.5 / 3.5 นิ้ว ↔ ช่องใส่ไดรฟ์ของเคส และพอร์ต SATA | ยังไม่เช็ก (มีข้อมูล แต่ยังไม่มีไดรฟ์แบบนี้ในเว็บ) |

## 7. ระบายความร้อน

| Format | รายละเอียด |
|---|---|
| ฮีทซิงก์ลม | เทียบความสูงเป็นมิลลิเมตรกับเคส |
| หม้อน้ำ | 120 / 140 / 240 / 280 / 360 / 420 มม. (จำนวนพัดลม × ขนาดพัดลม) |
| พัดลมเคส | 120 หรือ 140 มม. เป็นหลัก |

| ความสัมพันธ์ | สถานะ |
|---|---|
| ความสูงฮีทซิงก์ ↔ เคส | เช็กแล้ว |
| ขนาดหม้อน้ำ ↔ ตำแหน่งติดตั้งในเคส | ข้อมูลไม่พอ (ข้อมูลเคสไม่มีตำแหน่งติดหม้อน้ำ) |
| พัดลมเคส ↔ ตำแหน่งติดตั้ง | ข้อมูลไม่พอ |

## สรุปสิ่งที่ทำต่อได้ทันที

1. เพิ่มไดรฟ์ 2.5 / 3.5 นิ้ว แล้วเช็กกับช่องใส่ไดรฟ์ของเคส
2. เพิ่มแรม SO-DIMM และบอร์ดที่ใช้ แล้วเช็กรูปทรงแรม

สิ่งที่ต้องหาข้อมูลจากแหล่งอื่นก่อน: ตำแหน่งติดหม้อน้ำของเคส หัวจ่ายไฟของ PSU ความสูงแรม และความกว้างจริงของบอร์ด E-ATX
